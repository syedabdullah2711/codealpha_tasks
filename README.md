# CodeAlpha Hangman Game

A simple, interactive Hangman game built using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Random word selection from a predefined list of five words.
- Players guess the hidden word one letter at a time.
- Maximum of six incorrect attempts.
- Displays correctly guessed letters.
- Handles repeated and invalid guesses.
- Displays win and lose messages.

## Technologies Used

- Python 3
- Random module

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python3 hangman.py
```
